# Open Escool (English)

[Español](README.md) · [Italiano](README.it.md)

**Your personal school made of free videos.** Pick a topic and your assistant (Claude Code or Codex) does the rest:
- it finds the official sources and shows you the map of the path, for you to approve;
- it finds the best YouTube videos with the official API;
- Gemini watches each one and checks it against the sources;
- it builds a step-by-step path out of the right segments.

While you watch, ask the assistant what you don't understand. A step can also become a generated lesson, with animated cards
and a free voice.

Everything runs on your computer (Mac or Windows), with free APIs and the Claude or ChatGPT subscription you already have.

## Install
Paste into **Claude Code** or **Codex**:

```
Install Open Escool from https://github.com/marketingaios/open-escool: clone it into a folder of mine and follow /escool install ($escool install in Codex).
```

## Use
One command: `/escool` in Claude Code, `$escool` in Codex. On its own it shows the state of your paths and a menu:
- `create "topic"`, `update`, `reinforce`;
- `lesson`, `language`;
- `install`, `customize`, `start`, `diagnose`.

Interface in Italian, Spanish and English. Ready-made paths: ChatGPT Ads (videos in Italian, Spanish and English) and GEO
(videos in Spanish).
